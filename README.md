# 批量图片文字替换工具

批量识别图片中的文字（中英混合）并替换为其他文字，自动匹配原文字样式重绘。支持聊天记录截图头像替换与批量改名/改时间。提供 GUI 与无头批量两种模式。

## 功能

- **OCR 识别**：基于 RapidOCR（PaddleOCR 模型 + ONNX Runtime），中英混合识别
- **文字擦除**：OpenCV inpaint 修复背景，擦除原文字
- **样式自动匹配**：K-means 检测原文字颜色、bbox 高度推算字号、中英文字体自动分流
- **样式可手动覆盖**：字体/字号/颜色/加粗均可在配置或 GUI 中指定
- **Excel/CSV 配置**：支持全局规则与单图规则，精确/包含/正则三种匹配模式
- **头像替换**（聊天记录截图）：手动框选或自动检测圆形头像，更换为新头像图片，支持圆形/圆角/方形蒙版，可「仅当前图」或「所有图同位置」
- **快捷替换**：封装全局规则入口，便于批量改名/改时间
- **头像操作持久化**：导出/导入 JSON，便于对同模板截图复用
- **GUI**：图片上可视化标注 OCR 框，双击编辑，前后对比预览，头像替换即时预览
- **无头批量**：命令行一键处理整个目录，支持 `--avatar-ops` 单独或配合 `--config` 使用

## 环境要求

- Windows 10/11（依赖系统字体目录 `C:\Windows\Fonts`）
- Python 3.14（已在 3.14.5 验证；3.11–3.14 均可）

> ⚠️ 版本约束（经 PyPI 实证，请勿随意更改）：
> - `opencv-python` 必须 **5.0.0+**（4.13.x 在 Python 3.14 + numpy 2.x 下有 `_ARRAY_API` ABI bug）
> - `rapidocr` 用 **3.x**（不要用 `rapidocr-onnxruntime`，其 `requires_python<3.13`）
> - `PySide6` 用 **6.10.1+**（才支持 Python 3.14）

## 使用

### GUI 模式

```bash
python main.py
```

操作流程：
1. **导入图片**：工具栏「导入图片」选择一张或多张
2. **OCR 识别**：点「OCR-当前」或「OCR-全部」，图中文字框会以黄色半透明框标注
3. **编辑替换规则**：
   - 双击图中文字框 → 弹窗输入新文字与样式 → 自动加入规则表
   - 或在右侧规则表直接编辑「原文字/新文字/样式」列
   - 或选中文字框后在「样式面板」填新文字并「添加替换规则」
4. **头像替换**（聊天记录截图）：工具栏「替换头像」→ 在图上拖拽框选头像区域 → 弹窗选新头像/形状/范围 → 即时预览
   - 或「自动检测头像」→ 点击检测出的蓝色候选圆 → 弹窗确认
   - 右侧「头像替换操作」列表可删除/清空；菜单「文件 → 导入/导出头像操作」复用 JSON
5. **快捷改名/改时间**：工具栏「快捷替换」→ 填原文字/新文字/匹配方式 → 加入全局规则
6. **加载已有配置**：菜单「文件 → 加载配置」读入 xlsx/csv
7. **预览**：点「预览」查看当前图前后对比（含头像替换效果）
8. **批量执行**：点「批量执行」选输出目录，处理全部图片

> 头像替换流程：每张图先应用匹配的头像操作（不需 OCR），再 OCR + 文字替换。「所有图同位置」要求图片尺寸一致，否则位置会错位。

### 无头批量模式

```bash
# 仅文字替换
python main.py --batch --config config.xlsx --images ./imgs --out ./output

# 仅头像替换（无需 --config）
python main.py --batch --avatar-ops avatar_ops.json --images ./imgs --out ./out

# 头像 + 文字同时替换
python main.py --batch --config config.xlsx --avatar-ops avatar_ops.json --images ./imgs --out ./out
```

参数：
- `--config`：配置文件（xlsx/csv），可选（有 `--avatar-ops` 时可省略）
- `--avatar-ops`：头像操作 JSON 文件，可单独使用
- `--images`：图片文件或目录，可多个
- `--out`：输出目录（默认 `output`）
- `--erase-only`：仅擦除原文字不重绘（复杂背景可导出后外部精修）

#### 头像操作 JSON 格式

```json
[
  {
    "image_pattern": "*",
    "rect": [20, 20, 60, 60],
    "avatar_path": "C:/path/to/new_avatar.png",
    "shape": "circle"
  }
]
```

| 字段 | 说明 |
|---|---|
| `image_pattern` | `*` 或空 = 全局；文件名 = 单图（如 `chat1.png`） |
| `rect` | `[x, y, w, h]` 原图像素坐标 |
| `avatar_path` | 新头像图片绝对路径（中文路径支持） |
| `shape` | `circle`（默认）/ `rounded` / `square` |

## 配置表格式

列：`图片路径 | 匹配模式 | 原文字 | 新文字 | 字体 | 字号 | 颜色 | 加粗`（后 4 列可选，留空=自动匹配）

| 字段 | 说明 |
|---|---|
| 图片路径 | `*` 或空 = 全局规则；文件名 = 单图规则（如 `banner.png`） |
| 匹配模式 | `exact`（整框相等）/ `contains`（子串替换，保留框内其余文字）/ `regex`（正则替换）；空默认 `contains` |
| 原文字 | 要替换的文字 / 正则 |
| 新文字 | 替换后的文字（可含 `\n`） |
| 字体 | 如 `msyh.ttc`、`arial.ttf`，留空自动 |
| 字号 | 整数，留空按 bbox 自动估算 |
| 颜色 | `#RRGGBB`，留空自动检测 |
| 加粗 | `是`/`否` |

**优先级**：单图规则 > 全局规则；同框多规则命中按 精确 > 包含 > 正则。

生成模板：菜单「文件 → 生成配置模板」，或 GUI 首次使用时参考。

## 已知局限

1. **复杂纹理背景**：inpaint 对纯色/简单渐变背景效果好，对草地、文字、人脸等复杂纹理会模糊。应对：GUI 预览检查；用 `--erase-only` 导出后在外部工具精修；或调整擦除强度。
2. **颜色检测**：粗笔画文字（占比 >50%）可能误判。应对：在配置中手动指定颜色列。
3. **新文字过长**：超出原 bbox 时自动缩小字号，缩到最小仍放不下则按最小字号绘制（可能溢出），需手动缩短新文字。
4. **中英文字体**：重绘用单一字体（含中文用雅黑 ttc，纯英文用 arial），不实现逐字符切字体的复杂排版。
5. **艺术字体/手写体**：OCR 识别与样式匹配对非常规字体效果下降。
6. **首次 OCR**：RapidOCR 首次实例化加载模型约 1-2 秒，后续识别快。
7. **头像自动检测**：HoughCircles 在复杂背景/非正圆头像下不准，仅作辅助，手动框选为主。
8. **头像贴合边缘**：不处理原头像边缘抗锯齿/阴影，新头像边缘可能略生硬（已加轻羽化）。
9. **所有图同位置**：要求图片尺寸一致，否则位置错位。

## 技术栈

| 组件 | 技术 |
|---|---|
| OCR | RapidOCR 3.x + ONNX Runtime 1.28 |
| 图像修复 | OpenCV inpaint（TELEA / NS） |
| 文字重绘 | Pillow（二分查找字号 + 自动换行 + 居中） |
| 头像替换 | Pillow 形状蒙版（圆形/圆角/方形）+ 边缘羽化 |
| 头像检测 | OpenCV HoughCircles（辅助） |
| 样式检测 | K-means 聚类取文字色 + bbox 高度推算字号 |
| 配置 | openpyxl（Excel）/ csv（UTF-8-BOM） |
| 头像操作持久化 | JSON（UTF-8） |
| GUI | PySide6（QGraphicsView + QTableView） |
